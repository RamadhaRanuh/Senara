## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Please make sure you have Node.js and npm (Node Package Manager) installed.

### Installation

1.  Clone the repository (if applicable, otherwise assume local access):
    ```bash
    git clone [https://github.com/ramadharanuh/Senara.git](https://github.com/ramadharanuh/Senara.git)
    ```
2.  Navigate to the project directory:
    ```bash
    cd Senara
    ```
3.  Install NPM packages:
    ```bash
    npm install
    ```

## Usage

### Development

To run the project in development mode:
```bash
npm run dev
````

This will start the Vite development server.

### Build

To build the project for production:

```bash
npm run build
```

The built files will be located in the `dist` directory.

### Deployment

This project uses `gh-pages` for deployment to GitHub Pages.
To deploy:

```bash
npm run deploy
```

The homepage is set to `https://ramadharanuh.github.io/Senara`.

## Available Scripts

In the project directory, you can run:

  * `npm run dev`: Starts the development server.
  * `npm run build`: Builds the app for production to the `dist` folder.
  * `npm run lint`: Lints the codebase using ESLint.
  * `npm run preview`: Serves the production build locally.
  * `npm run predeploy`: Runs the build script before deployment.
  * `npm run deploy`: Deploys the `dist` folder to GitHub Pages.

## File Structure

The main structure of the project is as follows:

```
Senara/
├── .gitignore
├── README.md
├── index.html
├── package.json
├── package-lock.json
├── eslint.config.js
├── vite.config.js
└── src/
    ├── App.css
    ├── App.jsx
    ├── contact.jsx
    ├── index.css
    ├── main.jsx
    ├── product.jsx
    └── assets/
        └── ... (images and fonts used)
```

  * `public/`: Contains static assets like `logo.svg`.
  * `src/App.jsx`: The main application component, handling routing and the main page layout.
  * `src/contact.jsx`: Defines the Contact page component.
  * `src/product.jsx`: Defines the Products page component.
  * `src/main.jsx`: The entry point for the React application.
  * `src/index.css`, `src/App.css`: Global and component-specific stylesheets, including custom fonts like 'Glacial Indifference' and 'Liana'.
  * `vite.config.js`: Vite configuration file, setting up React plugin and Tailwind CSS, and base URL for deployment.
  * `eslint.config.js`: ESLint configuration for code quality.
  * `package.json`: Project metadata and script definitions.
